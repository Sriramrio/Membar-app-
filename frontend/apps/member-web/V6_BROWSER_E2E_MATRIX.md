# V6 Browser E2E Matrix — Current Readiness Contract

This matrix defines browser execution coverage. It does not claim execution where Playwright/project dependencies are unavailable.

## Identities
- `member`
- `secretary`
- `treasurer`
- `regional`
- `board`
- `statereviewer`
- `governancereviewer`
- `platform`
- `platformreviewer`
- `superadmin`
- `qa`

## Member
Login → Home → Directory → Member → Business → Back; connection/Converse; One-to-One; Opportunity; Business Outcome; relationship Notes; one-current-business rejection.

## Management
Role-scoped management routes, governed actions, denial behavior, dirty-navigation recovery.

## Governance
Decision/policy routes, deep links, permission denial, maker-checker visibility.

## Platform Admin
Identity/workflow/forms/audit/data-quality routes and privileged action visibility.

## Cross-resource/deep-link checks
Deep-link refresh, canonical origin/back recovery, invalid route recovery and focus/query state.

## Authorization acceptance
- denied routes remain denied
- visible actions match role responsibility
- no console/page errors in successful journeys
- no silent no-op or indefinite busy state
